# 3.4.2 前端 UI 设计规范

## 品牌定位

- 产品中文名：巡常临床数据智能管理系统
- 产品英文名：Xunchang Clinical Data Intelligence Management System
- 视觉方向：现代医疗 SaaS 后台 + 数据管理系统 + 轻量智能识别感
- 表达原则：克制专业、数据清晰、智能但不炫技、长期使用不疲劳
- 品牌层级：左侧为系统品牌，右上角为 Fortune 势通公司品牌

## 色彩 Token

| 用途 | Token | 色值 | 使用说明 |
| --- | --- | --- | --- |
| 主文本深蓝 | `brand-text` | `#10233F` | 标题、正文重点、导航文字 |
| 品牌深蓝 | `brand-navy` | `#0B2E63` | 主按钮、激活导航、核心强调 |
| 医疗蓝 | `brand-blue` | `#0F78D4` | 识别状态、链接、图表强调 |
| 智能青绿 | `brand-teal` | `#10BFB3` | OCR、确认、智能识别辅助强调 |
| Fortune 绿 | `fortune-green` | `#92C90E` | 公司 logo 与少量品牌呼应 |
| 页面背景 | `page-bg` | `#F5F8FB` | App 主背景 |
| 卡片背景 | `surface` | `#FFFFFF` | 内容容器、表格、表单 |
| 边框 | `border` | `#DDE7F0` | 卡片、输入框、分隔线 |

状态色保留原有语义，但降低饱和度：成功使用青绿浅底，警告使用 amber 浅底，风险使用 rose 浅底。

## 资产规范

- 公司 logo：`st-logo-compact-light.png`
  - 桌面端放在主应用右上角，推荐高度 28px。
  - 移动端保留右上角，最大宽度 112px。
  - 不放在左侧导航首位，避免与系统品牌抢层级。

- 系统图标：`xunchang-system-mark.png`
  - 来源于 `image.png` 主视觉裁切，适用于侧栏、移动顶栏、登录页。
  - 小尺寸推荐 36-44px，登录页主视觉推荐 64px。
  - 避免直接使用暗底 `图标.png` 作为小图标，暗底在白色后台中识别度不足。

## 布局与组件

- App 背景使用 `#F5F8FB`，内容区保持高密度但用浅边框分组。
- 侧栏使用白底、深蓝激活态、青绿色项目/中心细节态。
- 顶栏桌面端固定为白色半透明，右侧放版本标签和 Fortune logo。
- 卡片圆角 8px，边框 `#DDE7F0`，阴影极轻，避免营销卡片感。
- 表格保持紧凑，表头用深蓝灰，小字号，行分隔线使用浅边框。
- 主按钮使用 `#0B2E63`，次按钮白底浅边框，ghost 按钮使用浅蓝 hover。
- 输入框 focus 使用医疗蓝边框和 10% 蓝色 ring。

## 页面样板

- 登录页：左侧系统品牌与产品能力概览，右侧账号登录，右上 Fortune logo。
- 主应用骨架：左侧系统 icon + 系统名，右上公司 logo，内容区保持数据后台密度。
- 看板首屏：指标卡、趋势卡、风险卡用统一卡片与状态色表达。
- 临床数据集页：左侧项目中心树、右侧资料列表与阶段状态，强调扫描和确认状态。
- 项目/方案解析页：OCR 来源、中心风险、证据摘要和确认动作统一为智能识别工作流样式。

## 验收口径

- 前端构建通过：`cd frontend && npm run build`
- 如 lint 可用，运行 `cd frontend && npm run lint`
- 桌面端侧栏、顶栏、右上 logo 不挤压内容
- 移动端系统名不溢出，logo 保持可识别
- 登录页、看板、临床数据集、项目页首屏观感与设计稿一致
